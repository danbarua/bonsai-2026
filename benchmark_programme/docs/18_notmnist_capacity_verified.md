# Verification Result: The Archived-Artefact "Collapse" Does Not Reproduce -- Retracting the Prior Finding

## What this document is

A direct answer to the review's request: rerun the multi-threshold
notMNIST capacity experiment entirely from scratch, using only artifacts
whose provenance is verified as coming from the current pipeline, and
report whether the collapse described in the preliminary (now demoted)
document reproduces.

**It does not reproduce. The prior finding is retracted.**

**The methodological point this demonstrates matters more than either
number (36% or 84%).** An artifact can look like real evidence --
sensible standalone accuracies for each component, plausible feature
statistics, a repeatable (if catastrophic) result -- and still fail
independent reconstruction. That failure is only visible if reconstruction
is actually attempted; internal consistency alone would have signed off
on the collapse as real. **Reproducibility from independently-verified
components sits above internal self-consistency in the hierarchy of
evidence, and this is a concrete case of that principle catching a false
result before it became a cited finding**, not just an abstract
methodological preference.

## What was verified before running anything

- `notmnist_raw_stats_200.pkl` and `notmnist_ink_masks.pkl`: confirmed
  built by this pipeline earlier in this session's visible work.
- A fresh threshold=0.90 topology, rebuilt from these raw stats, is
  **bit-identical** to the previously-cached `notmnist_class_topologies_200.pkl`.
- A fresh threshold=0.95 topology, rebuilt the same way, gives **exactly
  the same edge counts per class** as the mystery-provenance
  `notmnist_topologies_095.pkl` (569, 938, 744, 1093, 715, 756, 781, 1106,
  2396, 855) -- so the topology-construction step, specifically, checks
  out. This answers part of the review's question directly: yes, at
  least this piece was generated by the current codebase.
- Fresh calibration baselines, computed independently, are bit-identical
  to the existing verified 20D baseline for the 0.90 threshold.

**What was not reused from the mystery artifacts at all**: the hybrid-head
training feature matrices and the test-set feature matrix. These were
rebuilt completely from scratch -- new dynamics runs, new scoring, new
normalization -- with zero dependency on any file of uncertain origin.

## The result

| Condition | Accuracy |
|---|---|
| 20D baseline (from within the verified pipeline) | 80.40% |
| **40D combined (0.90+0.95, verified, real)** | **84.00%** |
| 40D duplicated-20D control | 80.80% |
| 40 random-feature control | 83.60% |

**No collapse. A modest, genuine improvement**, with a well-balanced
prediction distribution across all 10 classes (43-61 predictions per
class) -- nothing resembling the mystery-file version's degenerate
"never predicts 6 of 10 classes" behavior. The real combination narrowly
exceeds both controls, but the random-feature control also improves
substantially (+3.2 points), so a meaningful part of the gain is
plausibly a generic dimensionality effect rather than uniquely
attributable to the second threshold's information -- the same character
of finding as Capacity Experiment I on Fashion-MNIST, just with a
somewhat larger absolute effect size here. This is a normal, unremarkable
result, which is itself the point.

## Paired significance tests, on the identical 500 test images

Raw accuracy percentages alone don't reveal whether two classifiers'
correct predictions are the same examples or genuinely different
successes. Two McNemar exact tests (binomial test on discordant pairs)
address this directly:

**20D vs. 40D (real, verified)**: of 500 test images, 393 both correct,
71 both wrong, and 36 discordant (9 where only 20D was right, 27 where
only 40D was right). **p=0.0039** -- a real, statistically significant
asymmetry. Going from 20D to 40D genuinely fixes more errors than it
introduces, more than chance would predict.

**40D real vs. 40D random-feature control**: of 500 test images, 390 both
correct, 52 both wrong, and 58 discordant (30 where only the real 40D was
right, 28 where only the random control was right). **p=0.896** -- no
significant difference. The specific pattern of which images the real
combination gets right, versus which the random control gets right, is
statistically indistinguishable from chance.

**Together, these two results are not in tension -- they answer different
questions precisely.** The 40D representation (real or random) reliably
improves on the 20D baseline in a way that isn't just noise. But *which*
40D representation is used -- real second-threshold information, or 40
random numbers with no relationship to the topology at all -- makes no
detectable difference. This sharpens, rather than just repeats, the
"modest genuine improvement, only partially distinguishable from
dimensionality effects" conclusion: the improvement itself is real
(confirmed by the first test), but its attribution to genuine
topology-derived information specifically is not supported (confirmed by
the second). Both statements should stand as written -- this is not
grounds to strengthen the claim that multi-threshold information helps.

## What this means about the mystery artifacts

What has actually been earned is narrower than assigning a cause: **the
archived artifacts cannot be reproduced by the current verified pipeline
and therefore should not be relied upon as evidence.** The topology-
construction step was verified correct (bit-identical rebuild), which is
consistent with the review's own observation that the per-block
standalone accuracies (69.6%, 73.4%, 77.8%) looked too sensible to be pure
junk. But something in how those individual blocks were *combined* in the
archived artifacts produced a spurious catastrophic result that a
correct, from-scratch rebuild does not reproduce -- and the specific cause
has not been identified. A buggy earlier implementation is one plausible
explanation, but so are an abandoned experimental branch, a different
normalization scheme, a different feature ordering, partially-generated
files, or stale intermediate outputs from an interrupted run. None of
these has been distinguished from the others, and none should be asserted
as the cause without further investigation. The archived artifacts should
now be treated exactly as the review recommended in advance: **historical
curiosities, not evidence.** The provenance question no longer matters for
the science, because the result no longer depends on those files -- though
it may still be worth resolving later out of curiosity about what
actually happened.

## Correction to the capacity-experiment programme's conclusion

The retracted finding would have meant Capacity Experiment I's
Fashion-MNIST-only conclusion ("combining thresholds is harmless")
doesn't generalize. **The corrected, verified finding is closer to the
opposite**: on notMNIST, combining thresholds gives a modest genuine
improvement, only partially distinguishable from generic dimensionality
effects -- not dramatically different in character from Fashion-MNIST's
"no clear benefit, no clear harm" result, just shifted slightly toward
"small benefit" rather than "no benefit." The two datasets now tell a
broadly consistent story, not a contradictory one. This is a considerably
less dramatic conclusion than the retracted version, and that is exactly
what makes it trustworthy.

## The methodological lesson, stated plainly

An unverified artifact produced a result dramatic enough to be
immediately interesting and nearly got written up as a real, load-bearing
finding on the strength of internal-consistency checks alone. Internal
consistency (each block sensible in isolation, plausible column
statistics) was necessary but not sufficient evidence. Only an
independent, from-scratch rebuild -- checking the construction pipeline
step by step against known-good outputs before trusting the final number
-- caught this. This is now the standard this project holds unverified
artifacts to before they are used as evidence, not just a one-time fix.
